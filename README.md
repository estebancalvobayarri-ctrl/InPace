# InPace

Web inicial para **InPace**, un espacio digital de homenaje y memoria para personas fallecidas, accesible también mediante un código QR.

## Publicar con GitHub Pages

1. En el repositorio, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama **main** y la carpeta **/(root)**.
4. Guarda los cambios. GitHub publicará la web y mostrará la URL de acceso.

La página se compone de `index.html`, `styles.css` y `script.js`, sin necesidad de instalar dependencias.
